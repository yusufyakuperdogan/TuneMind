# TuneMind

Emotion-based music app. FastAPI backend (backend/), plain HTML/CSS/JS frontend (frontend/).
Emotion detection uses Hugging Face (j-hartmann/emotion-english-distilroberta-base).

## Rules
- All code, comments and docs are in English.
- Never run git commit or git push. The user commits manually.
- Never commit or print secrets, .env, .cache, or *.db files.
